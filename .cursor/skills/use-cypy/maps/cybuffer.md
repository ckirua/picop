# cybuffer consumer map

Python: `picop.cybuffer`; package barrel: `picop`. Cython cimport: `picop.cybuffer` and package `picop`. Use `cpython.buffer` directly for flags; typed byte/memoryview helpers are preferable when concrete types are known.

| Symbol | Kind | Access | Decision | Expression or use | Contract | Python evidence | Cython evidence |
|---|---|---|---|---|---|---|---|
| <a id="buf_check"></a>`picop.cybuffer.buf_check` | function | both | candidate | `try: memoryview(obj); result = True` / `except (TypeError, BufferError): result = False` for ordinary buffer exporters | Checks the buffer slot without retaining a view; exceptions from exotic exporters may differ from the direct `PyObject_CheckBuffer` result. [stub](../../../../src/picop/cybuffer.pyi) | recorded: buffer hit cases 0.20–0.21x and misses 0.11–0.12x vs Python memoryview attempt, CPython 3.14.6 Linux, N=80,000; [tracker](../../../../docs/modules/017_cybuffer.md). | recorded: Tier B typed Cython hit ~0.99x; no material win vs Cython's typed check, CPython 3.14 Linux; [tracker](../../../../docs/modules/017_cybuffer.md). |
