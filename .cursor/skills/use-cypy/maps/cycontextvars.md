# cycontextvars consumer map

Python: `picop.cycontextvars`; package barrel: `picop`. Cython cimport: `picop.cycontextvars` and package `picop`. Python's `contextvars` module is the ordinary high-level interface; these wrappers expose CPython context APIs.
