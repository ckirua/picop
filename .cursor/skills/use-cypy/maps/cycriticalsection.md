# cycriticalsection

Cython-only critical-section primitives; import from `picop.cycriticalsection`. Their purpose is explicit locking/expressive synchronization, not drop-in Python speed replacement. See [pxd](../../../../src/picop/cycriticalsection.pxd), [shim](../../../../src/picop/cycriticalsection_shim.h), [tracker](../../../../docs/modules/070_cycriticalsection.md), and [Tier B driver](../../../../bench/tier_b/cycriticalsection.py).

| Symbol | Kind | Access | Decision | Expression or use | Contract | Python evidence | Cython evidence |
|---|---|---|---|---|---|---|---|
| <a id="PicopCriticalSection"></a>`picop.cycriticalsection.PicopCriticalSection` | type | cimport | companion | Stack-local critical-section guard in compiled extension. | Cython/C-level guard; lifetime must be lexical and held-object rules apply. See [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: type is Cython-only. | recorded: tracker reports measured lexical-vs-explicit cases on CPython 3.15.0rc2 free-threaded; context-specific, not Python speedup ([tracker](../../../../docs/modules/070_cycriticalsection.md#decision-log)). |
| <a id="PicopCriticalSection2"></a>`picop.cycriticalsection.PicopCriticalSection2` | type | cimport | companion | Two-object critical-section guard in compiled extension. | Two object locks follow CPython critical-section suspend/resume rules; see [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: Cython-only type. | recorded: tracker has two-object measurements on CPython 3.15.0rc2 free-threaded ([tracker](../../../../docs/modules/070_cycriticalsection.md#decision-log)). |
| <a id="critical_sections_enabled"></a>`picop.cycriticalsection.critical_sections_enabled` | function | cimport | specialized | Query whether critical sections are active in this build. | Build/runtime mode query; may be compile-time folded. See [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: Cython-only. | recorded: constant-folded in CPython 3.15 free-threaded run, not an ordinary runtime speed result ([tracker](../../../../docs/modules/070_cycriticalsection.md#decision-log)). |
| <a id="cs2_begin"></a>`picop.cycriticalsection.cs2_begin` | function | cimport | specialized | Begin explicit two-object section for non-lexical control flow. | Pair with matching `cs2_end`; strict stack/lifetime requirements. See [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: Cython-only. | not-measured: companion `cs2_begin_mutex` evidence does not isolate this operation ([tracker](../../../../docs/modules/070_cycriticalsection.md#decision-log)). |
| <a id="cs2_begin_mutex"></a>`picop.cycriticalsection.cs2_begin_mutex` | function | cimport | specialized | Begin two-object critical section while acquiring associated mutexes. | Suspend/resume semantics and lock ordering are essential; must pair with end. See [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: Cython-only. | recorded: 1.11x vs sequential pairs, CPython 3.15.0rc2 free-threaded Linux ([tracker](../../../../docs/modules/070_cycriticalsection.md#decision-log)). |
| <a id="cs2_end"></a>`picop.cycriticalsection.cs2_end` | function | cimport | specialized | End matching two-object critical section. | Must match active begin and preserve lock stack semantics; see [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: Cython-only. | not-measured: paired evidence not isolated. |
| <a id="cs_begin"></a>`picop.cycriticalsection.cs_begin` | function | cimport | specialized | Begin object critical section in compiled non-lexical control flow. | Must pair with `cs_end`; object lifetime and GIL/free-threaded rules apply. See [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: Cython-only. | recorded: explicit begin/end 0.94x lexical block case, CPython 3.15.0rc2 free-threaded Linux ([tracker](../../../../docs/modules/070_cycriticalsection.md#decision-log)). |
| <a id="cs_begin_mutex"></a>`picop.cycriticalsection.cs_begin_mutex` | function | cimport | specialized | Begin object section with mutex protection where object critical section is needed. | Locking is more expensive than bare mutex pair; matching end required. See [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: Cython-only. | recorded: 1.61x vs bare mutex pair, CPython 3.15.0rc2 free-threaded Linux; expressiveness case, not speedup ([tracker](../../../../docs/modules/070_cycriticalsection.md#decision-log)). |
| <a id="cs_end"></a>`picop.cycriticalsection.cs_end` | function | cimport | specialized | End matching object critical section. | Must match begin and preserve lock stack/lifetime rules; see [pxd](../../../../src/picop/cycriticalsection.pxd). | not-applicable: Cython-only. | not-measured: begin/end pair measured together only ([tracker](../../../../docs/modules/070_cycriticalsection.md#decision-log)). |
