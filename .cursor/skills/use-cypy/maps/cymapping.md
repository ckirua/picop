# cymapping consumer map

Python: `picop.cymapping`; package barrel: `picop`. Cython cimport: `picop.cymapping` and package `picop`. Abstract mapping-protocol operations accept mapping-capable objects; prefer `cydict` helpers when the concrete operand is known to be a dict. cdef-only `*_string` spellings are Cython-only; preferred public spelling is `*_cstr`.
