# cyversion consumer map

Cython cimport: `picop.cyversion`. CPython version macros re-exported at compile time; use these to gate ABI-dependent Cython code, not as Python runtime helpers.

| Symbol | Kind | Access | Decision | Expression or use | Contract | Python evidence | Cython evidence |
|---|---|---|---|---|---|---|---|
| <a id="PY_MAJOR_VERSION"></a>`picop.cyversion.PY_MAJOR_VERSION` | constant | cimport | companion | Compile-time `IF PY_MAJOR_VERSION >= 3` ABI conditional | Value is the Python headers' build target, not necessarily runtime metadata. [pxd](../../../../src/picop/cyversion.pxd) | not-applicable: runtime `sys.version_info` is distinct from compile-time headers. | not-applicable: compile-time macro only; [tracker](../../../../docs/modules/052_cyversion.md) |
| <a id="PY_MINOR_VERSION"></a>`picop.cyversion.PY_MINOR_VERSION` | constant | cimport | companion | Compile-time minor-version feature gate | Header/build version, not runtime interpreter query. [pxd](../../../../src/picop/cyversion.pxd) | not-applicable: use `sys.version_info` only for runtime checks. | not-applicable: compile-time macro only; [tracker](../../../../docs/modules/052_cyversion.md) |
| <a id="PY_MICRO_VERSION"></a>`picop.cyversion.PY_MICRO_VERSION` | constant | cimport | companion | Compile-time micro-version check where ABI compatibility requires it | Header version; compile target can differ from runtime.
