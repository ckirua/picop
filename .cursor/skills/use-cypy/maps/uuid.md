# UUID

Python imports: `from picop.uuid import UUID, uuid4, uuid4_bytes`. These exports are separate from the `cy` barrel. `UUID` is implemented in `picop.uuid._uuid`; its explicitly stubbed members below are part of this map. Cython access: `from picop.uuid cimport UUID, uuid4, uuid4_bytes`; details in [`src/picop/uuid/_uuid.pyi`](../../../../src/picop/uuid/_uuid.pyi), [`src/picop/uuid/_uuid.pxd`](../../../../src/picop/uuid/_uuid.pxd), and [`src/picop/uuid/_uuid.pyx`](../../../../src/picop/uuid/_uuid.pyx).
