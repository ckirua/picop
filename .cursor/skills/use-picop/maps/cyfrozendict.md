# cyfrozendict consumer map

Python: `picop.cyfrozendict`; package barrel: `picop`. Cython cimport: `picop.cyfrozendict` and package `picop`. Frozendict is CPython 3.15+; on 3.14 checks return false and constructors raise `NotImplementedError` rather than returning mutable dicts. It is not a dict subtype.
