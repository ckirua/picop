# cylist consumer map

Python: `picop.cylist`; package barrel: `picop`. Cython cimport: `picop.cylist` and package `picop`. Cython-only builder helpers `list_new` / `list_set` and their soft cimport spellings `lnew` / `lset` are cdef-only; see tracker inventory. These helpers target typed lists; no claim of safety under concurrent mutation.
