# cymethod consumer map

Python: `picop.cymethod`; package barrel: `picop`. Cython cimport: `picop.cymethod` and package `picop` where re-exported. The direct example cimports `cfunction_check`, `cfunction_get_self`, `classmethod_new`, and `staticmethod_new` from `picop.cymethod` ([demo](../../../../examples/cimport_ext/demo.pyx)). Ordinary Python bound-method attributes and builtins are the high-level interfaces.
