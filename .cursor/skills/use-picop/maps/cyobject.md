# cyobject consumer map

Python: `picop.cyobject`; package barrel: `picop`. Cython cimport: `picop.cyobject` and package `picop` where re-exported. The documented direct example cimports `obj_call` ([demo](../../../../examples/cimport_ext/demo.pyx)). Use ordinary Python object protocols when possible; this module is an abstract-object bridge, not a replacement for typed Core helpers.
